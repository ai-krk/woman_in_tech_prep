# Workshop Materials

This folder contains the preparation materials for the **VS Code + Jupyter + Gemini** workshop.

## Workshop repository

The complete workshop materials are maintained in the public GitHub repository:

**[github.com/ai-krk/woman_in_tech](https://github.com/ai-krk/woman_in_tech)**

The repository may be private or temporarily unavailable before the workshop. The organizers will provide access to the complete workshop package when it is released.

Please complete the preparation at least **48 hours before the workshop**. The preflight notebook usually takes about **30–45 minutes** to complete.

## What is included

- **`PREPARE_YOUR_LAPTOP_EN.pdf`** - Laptop setup instructions. Please send this document to participants at least 48 hours before the workshop.
- **`00_Preflight_EN.ipynb`** - A preparation check to run in desktop VS Code. It checks Python, the workshop packages, the local environment and, when approved by the organizer, access to Gemini.
- **`requirements.txt`** - The required Python packages and pinned versions.

This preparation repository intentionally contains only the files listed above. The full workshop repository contains the main notebook, handbook and helper files: [github.com/ai-krk/woman_in_tech](https://github.com/ai-krk/woman_in_tech). It includes `01_Recruitment_Coach_EN.ipynb`, `WORKSHOP_HANDBOOK_EN.html` and the other workshop files.

## Recommended order

1. Read **`PREPARE_YOUR_LAPTOP_EN.pdf`** and complete the setup.
2. Open **`00_Preflight_EN.ipynb`** in desktop VS Code.
3. Select the workshop `.venv` kernel and run the notebook one cell at a time.
4. Send the organizer the two check statuses and your operating system if requested. Never send an API key.
5. On the workshop day, download or open `01_Recruitment_Coach_EN.ipynb` from the [main workshop repository](https://github.com/ai-krk/woman_in_tech) when the facilitator asks. The filename is case-sensitive.
6. Use `WORKSHOP_HANDBOOK_EN.html` from the main workshop repository as a reference in your browser.

## Important security notes

- Use only your own organizer-approved AI Studio authentication key.
- Enter the key only when the notebook displays the hidden prompt.
- Never paste the key into notebook code, chat, forms, screenshots or messages.
- Do not enable paid billing to make the preparation check pass.
- Before sharing the notebook, set `CONNECT` and `RUN_LIVE` back to `False`, restart the kernel and clear the outputs.
